# Backend (PHP + MongoDB) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API w PHP (Slim 4) na hosting współdzielony OVH, obsługujące publiczne treści, panel admina z rolami admin/user, upload zdjęć/PDF i motywy sezonowe.

**Architecture:** Slim 4 jako cienki router + middleware; logika w klasach `*Service`, dostęp do MongoDB Atlas w klasach `*Repository`, mapowanie dokumentów na JSON w `*Presenter`. Wszystkie obiekty składane ręcznie w `Services` (bez kontenera DI). Testy integracyjne uruchamiają całą aplikację Slim in-process na testowej bazie Mongo (Docker).

**Tech Stack:** PHP 8.4, slim/slim 4, slim/psr7, mongodb/mongodb 1.15.x (ext-mongodb 1.15.3), firebase/php-jwt 6, ezyang/htmlpurifier 4, vlucas/phpdotenv 5, PHPUnit 11, Docker (tylko dev/test).

**Spec:** `docs/superpowers/specs/2026-10-15-przedszkole-design.md`

**Powiązany plan:** `docs/superpowers/plans/2026-10-15-frontend.md` (front korzysta z kontraktu z Task B0).

## Global Constraints

- **NIE commitujemy.** Zamiast kroku „Commit” każdy task kończy się krokiem „Checkpoint” — pełne testy zielone, zmiany zostają w working tree. Commity robi właściciel repo.
- PHP `^8.4` (OVH: 8.4.22, ustawiane `.ovhconfig` w folderze nowej strony — działający projekt zostaje na 7.4), `declare(strict_types=1);` w każdym pliku PHP.
- **OVH (sprawdzone 2026-10-16): PHP 8.4.22 + `ext-mongodb` 1.15.3.** Biblioteka `mongodb/mongodb` przypięta do `~1.15.0` (wersje 1.16+ wymagają ext ≥ 1.16 i nie zadziałają na serwerze). `composer.json` ma `config.platform` z wersjami z OVH, żeby Composer nigdy nie dobrał paczki, której serwer nie obsłuży — nawet gdy lokalny Docker ma nowsze rozszerzenie. Przed wdrożeniem warto powtórzyć test `wersja.php`, bo OVH aktualizuje obrazy.
- Wszystkie trasy mają prefiks `/api` (bez `setBasePath`).
- Strefa czasowa logiki dat: `Europe/Warsaw`. Daty w Mongo jako `UTCDateTime`, w JSON jako ISO 8601 (`DATE_ATOM`) w strefie Warsaw.
- Format błędu: `{"error":{"code":"STRING","message":"tekst po polsku"}}`; 500 bez szczegółów przy `APP_ENV=prod`.
- Komunikaty dla użytkownika po polsku, identyfikatory w kodzie po angielsku.
- Limity: zdjęcie ≤ 2 MB, miniatura ≤ 300 KB, PDF ≤ 10 MB, maks. 30 zdjęć na wpis, hasło ≥ 10 znaków, access token 60 min, refresh token 14 dni, 5 nieudanych logowań / 15 min (IP i e-mail).
- Typy obrazów: `image/webp` (`.webp`) i `image/jpeg` (`.jpg`) — JPEG to fallback dla Safari, które nie koduje WebP z canvasa.
- Grupy w seedzie: Ananaski, Pingwinki, Tygryski, Kangurki.
- CORS: nie implementujemy — w dev front łączy się przez proxy `ng serve`, na produkcji front i API są w tej samej domenie.

`backend/tests/ApiTestCase.php`:
```php
<?php
declare(strict_types=1);

namespace Tests;

use App\AppFactory;
use App\Config;
use App\Database;
use App\Support\FixedClock;
use PHPUnit\Framework\TestCase;
use Psr\Http\Message\ResponseInterface;
use Slim\App;
use Slim\Psr7\Factory\ServerRequestFactory;

abstract class ApiTestCase extends TestCase
{
    protected App $app;
    protected Database $db;
    protected FixedClock $clock;
    protected Config $config;
    protected string $uploadDir;

    protected function setUp(): void
    {
        $this->uploadDir = sys_get_temp_dir() . '/przedszkole-test-' . bin2hex(random_bytes(4));
        mkdir($this->uploadDir, 0777, true);
        $this->config = Config::fromEnv([
            'APP_ENV' => getenv('APP_ENV'),
            'MONGO_URI' => getenv('MONGO_URI'),
            'MONGO_DB' => getenv('MONGO_DB'),
            'JWT_SECRET' => getenv('JWT_SECRET'),
            'UPLOAD_DIR' => $this->uploadDir,
        ]);
        $this->clock = new FixedClock(new \DateTimeImmutable('2026-10-15 12:00:00', new \DateTimeZone('Europe/Warsaw')));
        $this->db = Database::connect($this->config);
        $this->db->drop();
        $this->db->ensureIndexes();
        $this->app = AppFactory::create($this->config, $this->db, $this->clock);
    }

    protected function tearDown(): void
    {
        $it = new \RecursiveIteratorIterator(
            new \RecursiveDirectoryIterator($this->uploadDir, \FilesystemIterator::SKIP_DOTS),
            \RecursiveIteratorIterator::CHILD_FIRST
        );
        foreach ($it as $f) {
            $f->isDir() ? rmdir($f->getPathname()) : unlink($f->getPathname());
        }
        rmdir($this->uploadDir);
    }

    /**
     * @param array<string,string> $cookies
     * @param array<string,mixed> $files  PSR-7 UploadedFileInterface keyed by field name
     * @param array<string,string> $server
     */
    protected function request(
        string $method,
        string $path,
        ?array $body = null,
        ?string $token = null,
        array $cookies = [],
        array $files = [],
        array $server = []
    ): ResponseInterface {
        $req = (new ServerRequestFactory())->createServerRequest($method, $path, $server + ['REMOTE_ADDR' => '127.0.0.1']);
        if ($body !== null) {
            $req = $files === []
                ? $req->withHeader('Content-Type', 'application/json')->withParsedBody($body)
                : $req->withParsedBody($body);
        }
        if ($token !== null) {
            $req = $req->withHeader('Authorization', 'Bearer ' . $token);
        }
        if ($cookies !== []) {
            $req = $req->withCookieParams($cookies);
        }
        if ($files !== []) {
            $req = $req->withUploadedFiles($files);
        }
        return $this->app->handle($req);
    }

    /** @return array<mixed> */
    protected function json(ResponseInterface $res): array
    {
        return json_decode((string) $res->getBody(), true, 512, JSON_THROW_ON_ERROR);
    }
}
```

`backend/src/Config.php`:
```php
<?php
declare(strict_types=1);

namespace App;

final class Config
{
    public function __construct(
        public readonly string $env,
        public readonly string $mongoUri,
        public readonly string $mongoDb,
        public readonly string $jwtSecret,
        public readonly string $uploadDir,
    ) {
    }

    /** @param array<string,mixed> $env */
    public static function fromEnv(array $env): self
    {
        foreach (['MONGO_URI', 'MONGO_DB', 'JWT_SECRET', 'UPLOAD_DIR'] as $key) {
            if (empty($env[$key])) {
                throw new \RuntimeException("Brak zmiennej konfiguracyjnej $key");
            }
        }
        if (strlen((string) $env['JWT_SECRET']) < 32) {
            throw new \RuntimeException('JWT_SECRET musi mieć co najmniej 32 znaki');
        }
        return new self(
            (string) ($env['APP_ENV'] ?? 'prod'),
            (string) $env['MONGO_URI'],
            (string) $env['MONGO_DB'],
            (string) $env['JWT_SECRET'],
            rtrim((string) $env['UPLOAD_DIR'], '/'),
        );
    }

    public function isProd(): bool
    {
        return $this->env === 'prod';
    }
}
```

```php
namespace App\Support;

final class FixedClock implements Clock
{
    public function __construct(private \DateTimeImmutable $now)
    {
    }

    public function now(): \DateTimeImmutable
    {
        return $this->now;
    }

    public function set(\DateTimeImmutable $now): void
    {
        $this->now = $now;
    }

    public function advance(string $modifier): void
    {
        $this->now = $this->now->modify($modifier);
    }
}
```

```php
            $slug = "$base-$i";
        }
        return $slug;
```

```php
    /** @return array<string,mixed> */
    public static function body(ServerRequestInterface $request): array
    {
        $body = $request->getParsedBody();
        if (!is_array($body)) {
            throw ApiException::validation('Nieprawidłowe dane wejściowe.');
        }
        return $body;
    }

    /** @param array<string,mixed> $d */
    public static function string(array $d, string $key, int $max, bool $required = true): string
    {
        $v = $d[$key] ?? '';
        if (!is_string($v)) {
            throw ApiException::validation("Pole $key musi być tekstem.");
        }
        $v = trim($v);
        if ($required && $v === '') {
            throw ApiException::validation("Pole $key jest wymagane.");
        }
        if (mb_strlen($v, 'UTF-8') > $max) {
            throw ApiException::validation("Pole $key może mieć maksymalnie $max znaków.");
        }
        return $v;
    }

    /** @param array<string,mixed> $d */
    public static function bool(array $d, string $key): bool
    {
        $v = $d[$key] ?? false;
        if (!is_bool($v)) {
            throw ApiException::validation("Pole $key musi mieć wartość true lub false.");
        }
        return $v;
    }

    /** @param array<string,mixed> $d */
    public static function int(array $d, string $key, int $default = 0): int
    {
        $v = $d[$key] ?? $default;
        if (!is_int($v)) {
            throw ApiException::validation("Pole $key musi być liczbą całkowitą.");
        }
        return $v;
    }

     * @param array<string,mixed> $d
     * @param list<string> $allowed
     */
    public static function oneOf(array $d, string $key, array $allowed): string

            throw ApiException::validation("Pole $key ma niedozwoloną wartość.");
```

```php
final class SeasonCalculator

    /** @param array<string,string> $starts key => 'MM-DD' */
    public static function seasonFor(\DateTimeImmutable $date, array $starts): string
    {
        $md = $date->setTimezone(new \DateTimeZone('Europe/Warsaw'))->format('m-d');
        asort($starts, SORT_STRING);

            }
        }
```

```php
<?php
declare(strict_types=1);

namespace App\Seed;

use App\Database;
use App\Support\Clock;
use App\Support\Dates;
use App\Support\Slugger;
use App\Theme\DefaultThemes;

final class Seeder
{
    private const GROUPS = ['Ananaski', 'Pingwinki', 'Tygryski', 'Kangurki'];

    public function __construct(private readonly Database $db, private readonly Clock $clock)
    {
    }

    /**
     * @param array{email:string,password:string,name:string}|null $admin
     * @return array{groups:int, themes:int, settings:bool, admin:bool}
     */
    public function run(?array $admin): array
    {
        $result = ['groups' => 0, 'themes' => 0, 'settings' => false, 'admin' => false];

        foreach (self::GROUPS as $i => $name) {
            $slug = Slugger::slugify($name);
            $r = $this->db->collection('groups')->updateOne(
                ['slug' => $slug],
                ['$setOnInsert' => ['name' => $name, 'slug' => $slug, 'order' => $i + 1, 'description' => '']],
                ['upsert' => true]
            );
            $result['groups'] += $r->getUpsertedCount();
        }

        foreach (DefaultThemes::all() as $theme) {
            $r = $this->db->collection('themes')->updateOne(['key' => $theme['key']], ['$setOnInsert' => $theme], ['upsert' => true]);
            $result['themes'] += $r->getUpsertedCount();
        }

        $r = $this->db->collection('settings')->updateOne(
            ['_id' => 'site'],
            ['$setOnInsert' => ['themeMode' => 'auto', 'manualThemeId' => null]],
            ['upsert' => true]
        );
        $result['settings'] = $r->getUpsertedCount() === 1;

        if ($admin !== null) {
            if (mb_strlen($admin['password']) < 10) {
                throw new \InvalidArgumentException('Hasło administratora musi mieć co najmniej 10 znaków.');
            }
            $email = mb_strtolower(trim($admin['email']));
            $r = $this->db->collection('users')->updateOne(
                ['email' => $email],
                ['$setOnInsert' => [
                    'email' => $email,
                    'passwordHash' => password_hash($admin['password'], PASSWORD_DEFAULT),
                    'name' => $admin['name'],
                    'role' => 'admin',
                    'active' => true,
                    'createdAt' => Dates::now($this->clock),
                ]],
                ['upsert' => true]
            );
            $result['admin'] = $r->getUpsertedCount() === 1;
        }

        return $result;
    }
}
```

```php
<?php
declare(strict_types=1);

namespace App\Auth;

use App\Config;
use App\Http\ApiException;
use App\Support\Clock;
use Firebase\JWT\JWT;
use Firebase\JWT\Key;

final class JwtService
{
    public const ACCESS_TTL = 3600;
    public const REFRESH_TTL = 14 * 86400;

    public function __construct(private readonly Config $config, private readonly Clock $clock)
    {
    }

    public function issueAccess(string $userId, string $role): string
    {
        $now = $this->clock->now()->getTimestamp();
        return JWT::encode(['sub' => $userId, 'role' => $role, 'typ' => 'access', 'iat' => $now, 'exp' => $now + self::ACCESS_TTL], $this->config->jwtSecret, 'HS256');
    }

    public function issueRefresh(string $userId): string
    {
        $now = $this->clock->now()->getTimestamp();
        return JWT::encode(['sub' => $userId, 'typ' => 'refresh', 'iat' => $now, 'exp' => $now + self::REFRESH_TTL], $this->config->jwtSecret, 'HS256');
    }

    /** @return array<string,mixed> */
    public function verify(string $token, string $type): array
    {
        JWT::$timestamp = $this->clock->now()->getTimestamp();
        try {
            $claims = (array) JWT::decode($token, new Key($this->config->jwtSecret, 'HS256'));
        } catch (\Throwable) {
            throw ApiException::unauthorized();
        } finally {
            JWT::$timestamp = null;
        }
        if (($claims['typ'] ?? '') !== $type || !is_string($claims['sub'] ?? null)) {
            throw ApiException::unauthorized();
        }
        return $claims;
    }
}
```

```php
namespace App\Auth;

use App\Database;
use App\Support\Clock;
use App\Support\Dates;

use MongoDB\Collection;

final class LoginRateLimiter
{
    private const LIMIT = 5;
    private const WINDOW_SECONDS = 900;
    private Collection $col;

    public function __construct(Database $db, private readonly Clock $clock)
    {
        $this->col = $db->collection('login_attempts');
    }

    public function tooManyAttempts(string $ip, string $email): bool
    {
        $since = new UTCDateTime(($this->clock->now()->getTimestamp() - self::WINDOW_SECONDS) * 1000);
        foreach (["ip:$ip", "email:$email"] as $key) {
            if ($this->col->countDocuments(['key' => $key, 'createdAt' => ['$gte' => $since]]) >= self::LIMIT) {
                return true;
            }
        }
        return false;
    }

    public function recordFailure(string $ip, string $email): void
    {
        $now = Dates::now($this->clock);
        $this->col->insertMany([['key' => "ip:$ip", 'createdAt' => $now], ['key' => "email:$email", 'createdAt' => $now]]);
    }

    public function clear(string $email): void
    {
        $this->col->deleteMany(['key' => "email:$email"]);
    }
}
```

```php
<?php
declare(strict_types=1);

namespace App\Auth;

use App\Http\ApiException;
use App\Http\Input;
use App\Http\Json;
use App\Http\RefreshCookie;
use App\Support\Ids;
use Psr\Http\Message\ResponseInterface as Response;
use Psr\Http\Message\ServerRequestInterface as Request;

final class AuthController
{
    public function __construct(
        private readonly UserRepository $users,
        private readonly JwtService $jwt,
        private readonly LoginRateLimiter $limiter,
    ) {
    }

    /**
     * @param array<string,mixed> $user
     * @return array{id:string,email:string,name:string,role:string}
     */
    public static function userPayload(array $user): array
    {
        return ['id' => (string) $user['_id'], 'email' => $user['email'], 'name' => $user['name'], 'role' => $user['role']];
    }

    public function login(Request $req, Response $res): Response
    {
        $body = Input::body($req);
        $email = mb_strtolower(Input::string($body, 'email', 254));
        $password = is_string($body['password'] ?? null) ? $body['password'] : '';
        $ip = (string) ($req->getServerParams()['REMOTE_ADDR'] ?? 'unknown');

        if ($this->limiter->tooManyAttempts($ip, $email)) {
            throw new ApiException(429, 'TOO_MANY_ATTEMPTS', 'Zbyt wiele nieudanych prób. Spróbuj ponownie za 15 minut.');
        }
        $user = $this->users->findByEmail($email);
        if ($user === null || !$user['active'] || !password_verify($password, $user['passwordHash'])) {
            $this->limiter->recordFailure($ip, $email);
            throw new ApiException(401, 'INVALID_CREDENTIALS', 'Nieprawidłowy e-mail lub hasło.');
        }
        $this->limiter->clear($email);

        $id = (string) $user['_id'];
        $res = RefreshCookie::set($res, $this->jwt->issueRefresh($id));
        return Json::write($res, ['accessToken' => $this->jwt->issueAccess($id, $user['role']), 'user' => self::userPayload($user)]);
    }

    public function refresh(Request $req, Response $res): Response
    {
        $token = $req->getCookieParams()[RefreshCookie::NAME] ?? '';
        if (!is_string($token) || $token === '') {
            throw ApiException::unauthorized();
        }
        $claims = $this->jwt->verify($token, 'refresh');
        $user = $this->users->findById(Ids::parse($claims['sub']));
        if ($user === null || !$user['active']) {
            throw ApiException::unauthorized();
        }
        return Json::write($res, ['accessToken' => $this->jwt->issueAccess((string) $user['_id'], $user['role']), 'user' => self::userPayload($user)]);
    }

    public function logout(Request $req, Response $res): Response
    {
        return RefreshCookie::clear($res)->withStatus(204);
    }
}
```

```php
<?php
declare(strict_types=1);

namespace App\Upload;

use App\Config;
use App\Http\ApiException;
use App\Support\Clock;
use App\Support\Uuid;
use Psr\Http\Message\UploadedFileInterface;

final class UploadService
{
    public const IMAGE_MAX = 2 * 1024 * 1024;
    public const THUMB_MAX = 300 * 1024;
    public const PDF_MAX = 10 * 1024 * 1024;
    public const IMAGE_CONTEXTS = ['posts', 'content'];
    private const IMAGE_TYPES = ['image/webp' => 'webp', 'image/jpeg' => 'jpg'];
    private const UUID = '[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}';

    public function __construct(private readonly Config $config, private readonly Clock $clock)
    {
    }

    /** @return array{file:string,thumb:string,w:int,h:int} */
    public function saveImage(UploadedFileInterface $image, UploadedFileInterface $thumb, string $context): array
    {
        if (!in_array($context, self::IMAGE_CONTEXTS, true)) {
            throw ApiException::validation('Nieprawidłowy kontekst pliku.');
        }
        $this->assertOk($image, self::IMAGE_MAX);
        $this->assertOk($thumb, self::THUMB_MAX);
        $ext = $this->detect($image, self::IMAGE_TYPES);
        $thumbExt = $this->detect($thumb, self::IMAGE_TYPES);

        $dir = $context . '/' . $this->clock->now()->format('Y/m');
        $id = Uuid::v4();
        $file = "$dir/$id.$ext";
        $thumbFile = "$dir/{$id}_thumb.$thumbExt";
        $this->move($image, $file);
        $this->move($thumb, $thumbFile);

        $size = @getimagesize($this->absolute($file)) ?: [0, 0];
        return ['file' => $file, 'thumb' => $thumbFile, 'w' => (int) $size[0], 'h' => (int) $size[1]];
    }

    /** @return array{file:string,name:string,size:int} */
    public function savePdf(UploadedFileInterface $upload): array
    {
        $this->assertOk($upload, self::PDF_MAX);
        $this->detect($upload, ['application/pdf' => 'pdf']);
        $file = 'docs/' . Uuid::v4() . '.pdf';
        $this->move($upload, $file);

        $name = mb_substr(basename((string) $upload->getClientFilename()), 0, 200);
        return ['file' => $file, 'name' => $name !== '' ? $name : 'dokument.pdf', 'size' => (int) filesize($this->absolute($file))];
    }

    public function isImagePath(string $path, string $context): bool
    {
        return in_array($context, self::IMAGE_CONTEXTS, true)
            && preg_match('#^' . $context . '/\d{4}/\d{2}/' . self::UUID . '(_thumb)?\.(webp|jpg)$#', $path) === 1;
    }

    public function isPdfPath(string $path): bool
    {
        return preg_match('#^docs/' . self::UUID . '\.pdf$#', $path) === 1;
    }

    public function delete(string $relativePath): void
    {
        $valid = $this->isPdfPath($relativePath)
            || $this->isImagePath($relativePath, 'posts')
            || $this->isImagePath($relativePath, 'content');
        if ($valid && is_file($this->absolute($relativePath))) {
            unlink($this->absolute($relativePath));
        }
    }

    private function absolute(string $relativePath): string
    {
        return $this->config->uploadDir . '/' . $relativePath;
    }

    private function assertOk(UploadedFileInterface $f, int $max): void
    {
        if (in_array($f->getError(), [UPLOAD_ERR_INI_SIZE, UPLOAD_ERR_FORM_SIZE], true) || (int) $f->getSize() > $max) {
            throw new ApiException(413, 'FILE_TOO_LARGE', 'Plik jest za duży.');
        }
        if ($f->getError() !== UPLOAD_ERR_OK) {
            throw ApiException::validation('Nie udało się przesłać pliku.');
        }
    }

    /** @param array<string,string> $types mime => ext */
    private function detect(UploadedFileInterface $f, array $types): string
    {
        $tmp = (string) $f->getStream()->getMetadata('uri');
        $mime = (new \finfo(FILEINFO_MIME_TYPE))->file($tmp);
        if (!is_string($mime) || !isset($types[$mime])) {
            throw ApiException::validation('Niedozwolony typ pliku.');
        }
        return $types[$mime];
    }

    private function move(UploadedFileInterface $f, string $relativePath): void
    {
        $target = $this->absolute($relativePath);
        if (!is_dir(dirname($target)) && !mkdir(dirname($target), 0755, true) && !is_dir(dirname($target))) {
            throw new \RuntimeException('Nie można utworzyć katalogu ' . dirname($target));
        }
        $f->moveTo($target);
    }
}
```

```php
namespace App\Group;
```

```php
use App\Http\ApiException;
use App\Http\Input;

final class GroupService
{
    public function __construct(private readonly GroupRepository $groups, private readonly Database $db)
    {
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function create(array $in): array
    {
        $doc = $this->validate($in);
        $doc['slug'] = Slugger::unique(Slugger::slugify($doc['name']), fn (string $s) => $this->groups->slugExists($s));
        $doc['_id'] = $this->groups->insert($doc);
        return $doc;
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function update(ObjectId $id, array $in): array
    {
        if ($this->groups->findById($id) === null) {
            throw ApiException::notFound();
        }
        $this->groups->update($id, $this->validate($in));
        return (array) $this->groups->findById($id);
    }

    public function delete(ObjectId $id): void
    {
        if ($this->groups->findById($id) === null) {
            throw ApiException::notFound();
        }
        $this->db->collection('posts')->updateMany(['targets.groupIds' => $id], ['$pull' => ['targets.groupIds' => $id]]);
        $this->groups->delete($id);
    }

    /**
     * @param array<string,mixed> $in
     * @return array{name:string,order:int,description:string}
     */
    private function validate(array $in): array
    {
        return [
            'name' => Input::string($in, 'name', 60),
            'order' => Input::int($in, 'order', 0),
```

```php
    {
        return $this->col->insertOne($doc)->getInsertedId();
    }

    /** @param array<string,mixed> $set */
    public function update(ObjectId $id, array $set): void

    }

    /** @return array<string,mixed>|null */
    public function findById(ObjectId $id): ?array

    {
        return $this->col->findOne(['slug' => $slug, 'status' => 'published']);
    }

    public function slugExists(string $slug): bool
    {
        return $this->col->countDocuments(['slug' => $slug]) > 0;
    }

    public function delete(ObjectId $id): void
    {
        $this->col->deleteOne(['_id' => $id]);
    }

    /**
     * @param array<string,mixed> $filter
     * @param array<string,int> $sort
     * @return array{items: list<array<string,mixed>>, total: int}
     */
    public function paginate(array $filter, array $sort, int $page, int $perPage): array
```

```php
<?php
declare(strict_types=1);

namespace App\Post;

use App\Group\GroupRepository;
use App\Http\ApiException;
use App\Http\AuthUser;
use App\Http\Input;
use App\Support\Clock;
use App\Support\Dates;
use App\Support\HtmlSanitizer;
use App\Support\Slugger;
use App\Upload\UploadService;
use MongoDB\BSON\ObjectId;

final class PostService
{
    public const MAX_IMAGES = 30;

    public function __construct(
        private readonly PostRepository $posts,
        private readonly GroupRepository $groups,
        private readonly HtmlSanitizer $sanitizer,
        private readonly UploadService $uploads,
        private readonly Clock $clock,
    ) {
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function create(array $in, AuthUser $user): array
    {
        $doc = $this->validate($in);
        $now = Dates::now($this->clock);
        $doc += [
            'slug' => Slugger::unique(Slugger::slugify($doc['title']), fn (string $s) => $this->posts->slugExists($s)),
            'publishedAt' => $doc['status'] === 'published' ? $now : null,
            'createdBy' => new ObjectId($user->id),
            'updatedBy' => new ObjectId($user->id),
            'createdAt' => $now,
            'updatedAt' => $now,
        ];
        $doc['_id'] = $this->posts->insert($doc);
        return $doc;
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function update(ObjectId $id, array $in, AuthUser $user): array
    {
        $old = $this->posts->findById($id) ?? throw ApiException::notFound();
        $set = $this->validate($in);
        $now = Dates::now($this->clock);
        $set['updatedBy'] = new ObjectId($user->id);
        $set['updatedAt'] = $now;
        if ($set['status'] === 'published' && ($old['publishedAt'] ?? null) === null) {
            $set['publishedAt'] = $now;
        }
        $this->posts->update($id, $set);

        $kept = array_merge(array_column($set['images'], 'file'), array_column($set['images'], 'thumb'));
        foreach ($old['images'] ?? [] as $img) {
            foreach ([$img['file'], $img['thumb']] as $path) {
                if (!in_array($path, $kept, true)) {
                    $this->uploads->delete($path);
                }
            }
        }
        return (array) $this->posts->findById($id);
    }

    public function delete(ObjectId $id): void
    {
        $post = $this->posts->findById($id) ?? throw ApiException::notFound();
        $this->posts->delete($id);
        foreach ($post['images'] ?? [] as $img) {
            $this->uploads->delete($img['file']);
            $this->uploads->delete($img['thumb']);
        }
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    private function validate(array $in): array
    {
        $body = $in['body'] ?? '';
        if (!is_string($body) || strlen($body) > 100_000) {
            throw ApiException::validation('Treść jest nieprawidłowa lub za długa.');
        }
        $targets = is_array($in['targets'] ?? null) ? $in['targets'] : [];

        return [
            'title' => Input::string($in, 'title', 200),
            'excerpt' => Input::string($in, 'excerpt', 500, false),
            'body' => $this->sanitizer->clean($body),
            'images' => $this->validateImages(Input::list($in, 'images')),
            'targets' => [
                'news' => Input::bool($targets, 'news'),
                'groupIds' => $this->validateGroupIds(Input::list($targets, 'groupIds')),
            ],
            'status' => Input::oneOf($in, 'status', ['draft', 'published']),
        ];
    }

    /**
     * @param list<mixed> $images
     * @return list<array{file:string,thumb:string,w:int,h:int,alt:string}>
     */
    private function validateImages(array $images): array
    {
        if (count($images) > self::MAX_IMAGES) {
            throw ApiException::validation('Wpis może mieć maksymalnie ' . self::MAX_IMAGES . ' zdjęć.');
        }
        $out = [];
        foreach ($images as $img) {
            if (!is_array($img)
                || !is_string($img['file'] ?? null) || !$this->uploads->isImagePath($img['file'], 'posts')
                || !is_string($img['thumb'] ?? null) || !$this->uploads->isImagePath($img['thumb'], 'posts')) {
                throw ApiException::validation('Nieprawidłowe zdjęcie.');
            }
            $out[] = [
                'file' => $img['file'],
                'thumb' => $img['thumb'],
                'w' => Input::int($img, 'w'),
                'h' => Input::int($img, 'h'),
                'alt' => Input::string($img, 'alt', 300, false),
            ];
        }
        return $out;
    }

    /**
     * @param list<mixed> $ids
     * @return list<ObjectId>
     */
    private function validateGroupIds(array $ids): array
    {
        $unique = [];
        foreach ($ids as $id) {
            if (!is_string($id) || !preg_match('/^[0-9a-f]{24}$/', $id)) {
                throw ApiException::validation('Nieznana grupa.');
            }
            $unique[$id] = new ObjectId($id);
        }
        $list = array_values($unique);
        if ($this->groups->countExisting($list) !== count($list)) {
            throw ApiException::validation('Nieznana grupa.');
        }
        return $list;
    }
}
```

```php
final class PostPresenter

    /**
     * @param array<string,mixed> $doc
     * @return array<string,mixed>
     */
    public static function toArray(array $doc, bool $admin = false): array
    {
        $out = [
            'id' => (string) $doc['_id'],
            'title' => $doc['title'],
            'slug' => $doc['slug'],
            'excerpt' => $doc['excerpt'] ?? '',
            'body' => $doc['body'] ?? '',
            'images' => $doc['images'] ?? [],
            'targets' => [
                'news' => (bool) ($doc['targets']['news'] ?? false),
                'groupIds' => array_map('strval', $doc['targets']['groupIds'] ?? []),
            ],
            'status' => $doc['status'],
            'publishedAt' => Dates::toIso($doc['publishedAt'] ?? null),
        ];
        if ($admin) {
            $out += [
                'createdBy' => (string) $doc['createdBy'],
                'updatedBy' => (string) $doc['updatedBy'],
                'createdAt' => Dates::toIso($doc['createdAt']),
                'updatedAt' => Dates::toIso($doc['updatedAt']),
            ];
        }
        return $out;
    }

    /**
     * @param array{items: list<array<string,mixed>>, total: int} $result
     * @return array{items: list<array<string,mixed>>, page:int, pages:int, total:int}
     */
    public static function paged(array $result, int $page, int $perPage, bool $admin): array
    {
        return [
            'items' => array_map(fn (array $d) => self::toArray($d, $admin), $result['items']),
            'page' => $page,
            'pages' => max(1, (int) ceil($result['total'] / $perPage)),
            'total' => $result['total'],
        ];
    }
```

```php
    public function __construct(Database $db)

        $this->col = $db->collection('content_items');
    }

    /** @return list<array<string,mixed>> */
    public function byPage(string $page, bool $publishedOnly): array
    {
        $filter = ['page' => $page] + ($publishedOnly ? ['status' => 'published'] : []);
        return $this->col->find($filter, ['sort' => ['order' => 1, 'createdAt' => 1]])->toArray();
    }

    public function findById(ObjectId $id): ?array
    {
        return $this->col->findOne(['_id' => $id]);
    }

    /** @param array<string,mixed> $doc */
    public function insert(array $doc): ObjectId
    {
        return $this->col->insertOne($doc)->getInsertedId();
    }

    /** @param array<string,mixed> $set */
    public function update(ObjectId $id, array $set): void
    {
        $this->col->updateOne(['_id' => $id], ['$set' => $set]);
    }

    public function delete(ObjectId $id): void
    {
        $this->col->deleteOne(['_id' => $id]);
    }
}
```

```php
<?php
declare(strict_types=1);

namespace App\Content;

use App\Http\ApiException;
use App\Http\Input;
use App\Support\Clock;
use App\Support\Dates;
use App\Support\HtmlSanitizer;
use App\Upload\UploadService;
use MongoDB\BSON\ObjectId;

final class ContentService
{
    public function __construct(
        private readonly ContentRepository $items,
        private readonly HtmlSanitizer $sanitizer,
        private readonly UploadService $uploads,
        private readonly Clock $clock,
    ) {
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function create(array $in): array
    {
        $doc = $this->validate($in);
        $doc['createdAt'] = $doc['updatedAt'] = Dates::now($this->clock);
        $doc['_id'] = $this->items->insert($doc);
        return $doc;
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function update(ObjectId $id, array $in): array
    {
        $old = $this->items->findById($id) ?? throw ApiException::notFound();
        $set = $this->validate($in);
        $set['updatedAt'] = Dates::now($this->clock);
        $this->items->update($id, $set);
        $kept = $this->files($set);
        foreach ($this->files($old) as $path) {
            if (!in_array($path, $kept, true)) {
                $this->uploads->delete($path);
            }
        }
        return (array) $this->items->findById($id);
    }

    public function delete(ObjectId $id): void
    {
        $old = $this->items->findById($id) ?? throw ApiException::notFound();
        $this->items->delete($id);
        foreach ($this->files($old) as $path) {
            $this->uploads->delete($path);
        }
    }

    /**
     * @param array<string,mixed> $doc
     * @return list<string>
     */
    private function files(array $doc): array
    {
        $paths = array_column($doc['attachments'] ?? [], 'file');
        foreach ($doc['images'] ?? [] as $img) {
            $paths[] = $img['file'];
            $paths[] = $img['thumb'];
        }
        return $paths;
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    private function validate(array $in): array
    {
        $body = $in['body'] ?? '';
        if (!is_string($body) || strlen($body) > 100_000) {
            throw ApiException::validation('Treść jest nieprawidłowa lub za długa.');
        }
        $attachments = [];
        foreach (Input::list($in, 'attachments') as $a) {
            if (!is_array($a) || !is_string($a['file'] ?? null) || !$this->uploads->isPdfPath($a['file'])) {
                throw ApiException::validation('Nieprawidłowy załącznik.');
            }
            $attachments[] = ['file' => $a['file'], 'name' => Input::string($a, 'name', 200), 'size' => Input::int($a, 'size')];
        }
        $images = [];
        foreach (Input::list($in, 'images') as $img) {
            if (!is_array($img)
                || !is_string($img['file'] ?? null) || !$this->uploads->isImagePath($img['file'], 'content')
                || !is_string($img['thumb'] ?? null) || !$this->uploads->isImagePath($img['thumb'], 'content')) {
                throw ApiException::validation('Nieprawidłowe zdjęcie.');
            }
            $images[] = ['file' => $img['file'], 'thumb' => $img['thumb'], 'w' => Input::int($img, 'w'), 'h' => Input::int($img, 'h'), 'alt' => Input::string($img, 'alt', 300, false)];
        }
        if (count($attachments) > 50 || count($images) > 30) {
            throw ApiException::validation('Za dużo plików w jednym elemencie.');
        }
        return [
            'page' => Input::oneOf($in, 'page', ContentPages::ALL),
            'title' => Input::string($in, 'title', 200),
            'body' => $this->sanitizer->clean($body),
            'attachments' => $attachments,
            'images' => $images,
            'order' => Input::int($in, 'order', 0),
            'status' => Input::oneOf($in, 'status', ['draft', 'published']),
        ];
    }
}
```

```php
    }
```

```php
<?php
declare(strict_types=1);

namespace App\Theme;

use App\Http\ApiException;
use App\Http\Input;
use App\Support\Slugger;
use MongoDB\BSON\ObjectId;

final class ThemeService
{
    private const PALETTE_KEYS = ['50', '100', '200', '300', '400', '500', '600', '700', '800', '900', 'accent', 'text'];

    public function __construct(private readonly ThemeRepository $themes, private readonly SettingsRepository $settings)
    {
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function create(array $in): array
    {
        $name = Input::string($in, 'name', 60);
        $doc = [
            'key' => Slugger::unique('special-' . Slugger::slugify($name), fn (string $k) => $this->themes->keyExists($k)),
            'name' => $name,
            'type' => 'special',
            'seasonStart' => null,
            'palette' => $this->palette($in['palette'] ?? null),
        ];
        $doc['_id'] = $this->themes->insert($doc);
        return $doc;
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function update(ObjectId $id, array $in): array
    {
        $theme = $this->themes->findById($id) ?? throw ApiException::notFound();
        $set = ['name' => Input::string($in, 'name', 60), 'palette' => $this->palette($in['palette'] ?? null)];
        if ($theme['type'] === 'season') {
            $set['seasonStart'] = $this->seasonStart(Input::string($in, 'seasonStart', 5));
        }
        $this->themes->update($id, $set);
        return (array) $this->themes->findById($id);
    }

    public function delete(ObjectId $id): void
    {
        $theme = $this->themes->findById($id) ?? throw ApiException::notFound();
        if ($theme['type'] === 'season') {
            throw ApiException::validation('Nie można usunąć motywu sezonowego.');
        }
        $settings = $this->settings->get();
        if ($settings['manualThemeId'] !== null && (string) $settings['manualThemeId'] === (string) $id) {
            $this->settings->save('auto', null);
        }
        $this->themes->delete($id);
    }

    /** @return array{themeMode:string, manualThemeId:?string} */
    public function settings(): array
    {
        $s = $this->settings->get();
        return ['themeMode' => $s['themeMode'], 'manualThemeId' => $s['manualThemeId'] !== null ? (string) $s['manualThemeId'] : null];
    }

    /**
     * @param array<string,mixed> $in
     * @return array{themeMode:string, manualThemeId:?string}
     */
    public function saveSettings(array $in): array
    {
        $mode = Input::oneOf($in, 'themeMode', ['auto', 'manual']);
        $manualId = null;
        if ($mode === 'manual') {
            $raw = $in['manualThemeId'] ?? null;
            if (!is_string($raw) || !preg_match('/^[0-9a-f]{24}$/', $raw) || $this->themes->findById(new ObjectId($raw)) === null) {
                throw ApiException::validation('Wybierz istniejący motyw.');
            }
            $manualId = new ObjectId($raw);
        }
        $this->settings->save($mode, $manualId);
        return $this->settings();
    }

    /** @return array<string,string> */
    private function palette(mixed $palette): array
    {
        if (!is_array($palette)) {
            throw ApiException::validation('Brak palety kolorów.');
        }
        $out = [];
        foreach (self::PALETTE_KEYS as $key) {
            $v = $palette[$key] ?? null;
            if (!is_string($v) || !preg_match('/^#[0-9a-fA-F]{6}$/', $v)) {
                throw ApiException::validation("Kolor $key musi mieć format #rrggbb.");
            }
            $out[$key] = strtolower($v);
        }
        return $out;
    }
```

```php
<?php
declare(strict_types=1);

namespace App\Auth;

use App\Http\ApiException;
use App\Http\AuthUser;
use App\Http\Input;
use App\Support\Clock;
use App\Support\Dates;
use MongoDB\BSON\ObjectId;

final class UserService
{
    public function __construct(private readonly UserRepository $users, private readonly Clock $clock)
    {
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function create(array $in): array
    {
        $email = mb_strtolower(Input::string($in, 'email', 254));
        if (filter_var($email, FILTER_VALIDATE_EMAIL) === false) {
            throw ApiException::validation('Nieprawidłowy adres e-mail.');
        }
        if ($this->users->findByEmail($email) !== null) {
            throw ApiException::validation('Użytkownik z tym e-mailem już istnieje.');
        }
        $doc = [
            'email' => $email,
            'passwordHash' => password_hash($this->password($in, true), PASSWORD_DEFAULT),
            'name' => Input::string($in, 'name', 100),
            'role' => Input::oneOf($in, 'role', ['admin', 'user']),
            'active' => true,
            'createdAt' => Dates::now($this->clock),
        ];
        $doc['_id'] = $this->users->insert($doc);
        return $doc;
    }

    /**
     * @param array<string,mixed> $in
     * @return array<string,mixed>
     */
    public function update(ObjectId $id, array $in, AuthUser $actor): array
    {
        $this->users->findById($id) ?? throw ApiException::notFound();
        $set = [
            'name' => Input::string($in, 'name', 100),
            'role' => Input::oneOf($in, 'role', ['admin', 'user']),
            'active' => Input::bool($in, 'active'),
        ];
        if ((string) $id === $actor->id && ($set['role'] !== 'admin' || !$set['active'])) {
            throw ApiException::validation('Nie możesz odebrać sobie uprawnień administratora ani się dezaktywować.');
        }
        $password = $this->password($in, false);
        if ($password !== '') {
            $set['passwordHash'] = password_hash($password, PASSWORD_DEFAULT);
        }
        $this->users->update($id, $set);
        return (array) $this->users->findById($id);
    }

    public function delete(ObjectId $id, AuthUser $actor): void
    {
        if ((string) $id === $actor->id) {
            throw ApiException::validation('Nie możesz usunąć własnego konta.');
        }
        $this->users->findById($id) ?? throw ApiException::notFound();
        $this->users->delete($id);
    }

    /** @param array<string,mixed> $in */
    private function password(array $in, bool $required): string
    {
        $p = $in['password'] ?? '';
        if (!is_string($p)) {
            throw ApiException::validation('Nieprawidłowe hasło.');
        }
        if (($required || $p !== '') && mb_strlen($p) < 10) {
            throw ApiException::validation('Hasło musi mieć co najmniej 10 znaków.');
        }
        return $p;
    }
```

```php
<?php
declare(strict_types=1);

namespace App\Upload;

use App\Config;
use App\Database;
use App\Support\Clock;

final class UploadCleaner
{
    private const MIN_AGE_SECONDS = 86400;

    public function __construct(private readonly Database $db, private readonly Config $config, private readonly Clock $clock)
    {
    }

    /** @return list<string> */
    public function run(bool $dryRun = false): array
    {
        $referenced = array_flip($this->referenced());
        $threshold = $this->clock->now()->getTimestamp() - self::MIN_AGE_SECONDS;
        $base = $this->config->uploadDir;
        $removed = [];

        $it = new \RecursiveIteratorIterator(new \RecursiveDirectoryIterator($base, \FilesystemIterator::SKIP_DOTS));
        foreach ($it as $file) {
            /** @var \SplFileInfo $file */
            if (!$file->isFile() || str_starts_with($file->getFilename(), '.')) {
                continue;
            }
            $rel = substr($file->getPathname(), strlen($base) + 1);
            if (isset($referenced[$rel]) || $file->getMTime() > $threshold) {
                continue;
            }
            if (!$dryRun) {
                unlink($file->getPathname());
            }
            $removed[] = $rel;
        }
        sort($removed);
        return $removed;
    }

    /** @return list<string> */
    private function referenced(): array
    {
        $paths = [];
        foreach ($this->db->collection('posts')->find([], ['projection' => ['images' => 1]]) as $doc) {
            foreach ($doc['images'] ?? [] as $img) {
                $paths[] = $img['file'];
                $paths[] = $img['thumb'];
            }
        }
        foreach ($this->db->collection('content_items')->find([], ['projection' => ['images' => 1, 'attachments' => 1]]) as $doc) {
            foreach ($doc['images'] ?? [] as $img) {
                $paths[] = $img['file'];
                $paths[] = $img['thumb'];
            }
            foreach ($doc['attachments'] ?? [] as $a) {
                $paths[] = $a['file'];
            }
        }
        return $paths;
    }
}
```
